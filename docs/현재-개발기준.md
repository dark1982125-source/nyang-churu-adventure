## 전투와 챕터
- 호냥이의 수평 이동은 오른쪽 전진만 가능. 왼쪽 이동·후퇴 없음. 대시 완전 폐기.
- 점프·자동 기본 공격·자동 전투 스킬·수동 궁극기 유지. 공격은 오른쪽 전방 기준.
- 챕터 1개가 한 판, 총 3웨이브. 각 끝에 엘리트 1/엘리트 2/보스.
- 일반 구간 잡몹은 계속 생성, 목표 처치 수 달성 시 잔여 잡몹 제거(처치/보상 없음) 후 엘리트·보스 등장. 해당 본체·분열/소환체 전멸 시 진행. 거리만으로 클리어하지 않음.
- 구출 챕터는 지정 적 전부 처치 후 보스 열쇠로 감옥 개방·정체 공개·구출 성공까지 마무리.
- 입력 중 오른쪽 전진·놓으면 정지, 캠프 동기 이동/정지·간격 유지. 웨이브 정차 유지. 점프 중에도 적 후방 통과 불가. 속도·거리·표시 수치는 미정.
- 후방 추격전·뒤돌아 공격·등 뒤로 넘어가야만 풀리는 기믹은 제외/재설계.
- 적이 지나쳐 뒤에 남는 경우에도 전부 처치 가능한 처리 필요. 우측만 이동하므로 놓친 필수 적 때문에 영구 진행 불가 상태가 생겨서는 안 됨. 구체 해법 미정.

## 대시 폐기 영향
- 선택창·버튼·냥기력 소모·쿨타임·대시용 잔량 확보 전부 삭제.
- 대시 부츠/대시 보조 옵션 폐기, 대체 효과 미정.
- 호냥이 영구 회피 스탯 자체의 폐기를 뜻하지는 않음. 회피 스탯 판정은 별도 미정.
- 조작 UI의 좌우 조이스틱은 재설계 필요. 전진 입력 형태는 아직 정하지 않았음.

## 성장·슬롯
- 호냥이: 작은 개다래 열매 경험치 → 호냥이 전용 3지선다.
- 캠프: 작은 톱니 경험치 → 캠프/합류 동료 지원 3지선다.
- 기본 공격 고정 별도 1개, 냥기력 무소모. 전투 중 강화 가능, 별도 슬롯 차지 없음. 등급 진화 없이 최대 레벨까지(상한 미정).
- 무기 전용 스킬: 무기별 5종 중 최대 3종 습득, 전 무기 공통 확정. 가득 차면 미보유 전용 스킬은 후보에서 제외.
- 대시 없음. 공통 패시브 후보 14종 중 최대 5종 보유·각 Lv.5, 등급 진화 없음. 미보유/최대 레벨 제외 규칙 확정. 상세는 `패시브-확정정리.md` 참조.
- 임시 기술 일반 Lv.1~3 → 유니크 Lv.1~3 → 전설. 행운으로 상위 등급 직접 획득 가능. 임시 성장은 판 종료 초기화.
- 영구 재화: 냥젤리(기본 스탯·행운)/황금 개다래(패시브·궁극기)/골골기어(캠프 트리).
- 추가 스킬은 냥기력·쿨타임 사용. 자연 회복·삼색이 보급 유지. 궁극기 별도 게이지, 캠프 지원 호냥이 기력 미소모.
- 궁극기 공격 광역/단일, 방어 감속/튕겨내기, 회복 호냥이/캠프 완전회복 6종, 최대 3종 장착·공유 게이지. 스킬 실제 발동별 차등 충전, 기본 공격 포함 여부 미정. 대시는 충전 대상 후보에서도 제외.

## 지원·이야기 유지
- 코숏 캣닢 캡슐/개다래 정화약·삼색이 기력 보급은 호냥이 앞쪽 투하, 접촉 자동 사용. 수집 범위 패시브는 약/츄르 포함 모든 드롭을 반경 내 흡인, 도착 시 자동 사용. 후퇴 회수 불가를 전제로 위치·소멸 처리 설계 필요.
- 수염할아버지 배리어·삐콩이 레이저·얼룩이 위장막·볼트 수리 유지.
- 나비는 액세서리·코스튬, 깡깡이는 무기·몸통/발 보호구 제작.
- 15챕터, 코숏 Ch 1/깡깡이 Ch 2/삼색이 Ch 3/볼트 Ch 4/나비 Ch 6/얼룩이 Ch 8 구출 유지.
- 전설 츄르 핵심 획득물 Ch 3/8/14, Ch 15 치유 결말 유지.
- 실패 시 누적 재화/제작 재료/이전 동료 보존. 신규 구출은 성공 시 확정.

## 최근 확정한 스킬 차별화
- 장갑: 우다다 냥냥냥냥!(가까운 적 처치 후 다음 적으로 연타)/폴짝폴짝 어퍼컷/쭉쭉 스트레이트(짧은 젤리 팔 관통)/꾹꾹이 꾹꾹(앞발 반복 광역)/골골냥냥파(전방 거대 에너지·기절).
- 검 ‘생선뼈 관통베기’ → ‘싹뚝싹뚝 슬러시’(넓은 관통 검기).
- 창 ‘수염 관통찌르기’ → ‘쐐애액 일점돌파’(길고 좁은 관통, 호냥이 강제 이동 없음).
- 마법봉 바람발톱: 여러 갈래로 퍼지는 관통 바람.
- 검 회오리: 전방 한 구역 체류 반복 타격. 창 회오리: 전방 이동 타격.
- 검 꼬리표: 지정 적 추적 연타. 창 백렬: 긴 직선 고정 범위, 벗어나면 빗나감.
- 천둥베기: 짧은 전기 불꽃 → 빠른 일격. 망치 강타: 큰 그림자 → 느린 순간 광역. 꾹꾹이: 앞발 그림자 → 번갈아 반복 광역. 준비 연출로 타격감 강조, 시간 미정.
- 런처 눈물쏙 츄르탄: 작은 매운맛 구름 지속 피해. 참치 대폭탄: 넓은 순간 폭발.

## 재논의 우선 목록
1. 카메라·캠프 간격 수치·밀쳐내기 경계·부하 카운트 표시. 전진/정지와 후방 통과 방지는 확정 완료.
2. 철깡통 기사 후방 약점·컨베이어 왼쪽 밀림·블랙홀 강제 이동 등 기존 기믹의 오른쪽 전진 규칙 적용 범위. 방패 해제 틈/파괴 약점은 제안, 확정 아님.
3. 후방으로 넘어간 표적 추적·부메랑 복귀 판정과 전방 공격 원칙의 관계.
4. 보급 투하 안전 위치·지속 시간·이동 불가 상태·놓친 재료 수집.
5. 기본 공격 강화 항목·패시브 수치·상한·대체 보상량. 기본 공격 Lv.5·캠프 임시 지원 Lv.5·대체 보상 종류 확정, 후속 문서 참조.
6. 나머지 기존 미정 수치·드롭량·장비/기술 진화·행운 공식·신규 보스.
