# 치료·상태이상·방어·클리어 보완 확정

정리일 2026-10-15. 이전 전달 이후 승인된 후속 기준. 충돌 시 이 문서 우선.

## 캠프 위협·클리어·표시
- 캠프의 주요 위협은 호냥이 전방의 원거리·공중 적. 원거리 투사체·공중 투하 공격으로 캠프 조준. 지상 근접은 호냥이 압박. 보스 기존 캠프 공격 유지.
- 적이 호냥이 뒤로 이동해 공격하는 방식은 복원하지 않음. 공격 조준/낙하 예고와 호냥이 공격·점프 요격 등 대응 수단 필요.
- Ch 1에 어떤 기존 적을 원거리화할지, 신규 공중 적을 넣을지 정확한 몬스터/빈도는 아직 미정. 먼저 시험안 제시 가능.
- 성공 시 필드에 남은 드롭 자동 회수. 실패/중도 종료는 이미 수집한 것만 보존.
- 회수 경험치의 임시 성장은 판 종료 초기화. 성공 직전 경험치로 최종 선택창을 여는지, 완료 정산 시 XP를 소비 처리할지는 미정. 완료 후 무의미한 선택창을 임의 확정하지 말 것.
- 일반 구간만 ‘처치 15/20’ 표시. 엘리트/보스 분열·소환체 잔여 숫자 표시 없음. 본체·분열/소환체 전멸 판정은 내부 유지.
- 감옥은 자동 회수 대상 아닌 직접 상호작용.

## 방어력
- 호냥이 최종 방어력 = 영구 스탯 + 장비 + 판 임시 보너스.
- 직접 피해 = 원래 피해 × 100/(100+방어력). 방어력 0/25/50/100에서 원래 100 피해는 100/80/약66.67/50.
- 직접 접촉·근접·투사체·폭발에 적용, 독·화상·출혈 DOT 및 용암/위험지형 지속 피해에는 미적용.
- 저항 장비·치료·위험구역 회피로 DOT 대응. 기존 TEMP 단순 % 방어 감소를 대체.
- 방어 패시브/장비의 실제 방어 포인트, 반올림·음수 방어·다른 감산 순서는 미정/임시 데이터. 캠프에 같은 공식 적용은 확정 아님.

## 코숏 치료품 — 6종
| 이름 | 효과 |
|---|---|
| 캣닢 캡슐 | HP 회복 |
| 개다래 정화약 | 독 해제 |
| 보송보송 붕대 | 출혈 해제 |
| 시원 민트연고 | 화상 해제 |
| 캡사이신 핫팩 | 빙결 해제 |
| 사뿐 냥카스 | 적 기술의 감속 해제 |

게임 내 고양이 전용 처방 연출. 실제 제품 정보/현실 사용법 아님.
- 지원 두 갈래: HP 회복 캣닢 캡슐 / 상태별 보급을 고르는 ‘증상별 처방’ 하나.
- 처방 순서: 빙결 → 감속 → 독/화상/출혈 중 현재 초당 피해 최대 효과.
- 한 처방 한 아이템, 다음 처방 때 증상 재판단. 해당 약이 바닥/비행 중이면 중복 투하 회피 방향. 동률 우선순위·기존 약이 있어 다른 증상 처방할지/대기할지는 미정.
- 전방 투하·접촉/흡인 도착 사용 유지. 필요 없어도 도착 소모·보관 없음. 빙결 중에도 반경 내 약 흡인 가능, 빙결 자체 시간 제한 필요.
- 골골기어 영구 스킬트리 진화로 ‘코숏의 만능 처방약’ 해금: 독·화상·출혈·빙결·기술 감속 동시 해제, HP 회복 아님.
- 지형 둔화/붙잡힘/캠프 바퀴 속박/스킬 봉인/모래폭풍 시야 가림은 치료 제외.
- 진화 후 기존 개별 약 대체/병행 여부, 해금 레벨·쿨타임·수치는 미정.

## 상태이상 중복
- 같은 독/화상/출혈은 피해 중첩하지 않고 강한 효과 유지, 지속 시간 갱신.
- 같은 빙결/감속은 강도 중첩 없이 지속 시간 갱신.
- 서로 다른 종류 동시 적용. 해당 치료품은 해당 종류 해제, 만능약은 치료 가능한 다섯 종류 모두 해제.
- 빙결 해제 후 짧은 재빙결 면역. 시간 미정.
- 낮은 강도 재적용이 강한 효과를 얼마 동안 연장할지 구체 시간 계산·플레이어/적 공통 적용 범위 미정. 상태 태그/출처/강도/시간을 분리해 준비.

## 적 수면 및 보스 저항
- 수면: 이동/공격 정지, 직접 피격 시 기상, DOT는 수면 유지. 엘리트는 시간 단축, 보스는 짧은 감속으로 대체.
- 적 기절/빙결: 일반 정상, 엘리트 시간 단축, 보스 행동정지 대신 짧은 감속.
- 밀쳐내기: 일반 정상, 엘리트 거리 감소, 보스 위치 이동 면역.
- 화상/출혈 등 DOT는 일반·엘리트·보스 적용. 제어 저항과 별개로 직접 피해 정상 적용.
- 감속 대체 수치·면역·보스 예외 미정. 보스를 기절시켜 패턴 취소하는 기존 제안은 공통 규칙과 충돌, 예외 확정 전 구현 금지.
- 수면탄 자체의 첫 타격과 수면 적용 순서 미정. 자동 공격에 즉시 깨어나는 빈도는 테스트 필요.
