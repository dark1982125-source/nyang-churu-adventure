# 1차 사용자 플레이 피드백

기록: 2026-10-15. 현재 프로토타입 직접 플레이 소감. 참고 기록이며 수치/세부 구현 확정이나 즉시 수정 지시가 아니다.

## 사용자 의견
- 전진은 자동으로 진행하는 편이 좋겠다. 현재 호냥이가 제자리에 머물러 적이 올 때까지 기다리는 시간이 길고 공격을 맞기만 하는 느낌.
- 공격 범위 수정, 호냥이 전진 변경 또는 두 가지 모두의 개선이 필요.
- 점프의 필요성이 불명확하고 공중 적 처치에도 애매함. 즉시 삭제하지는 않고 유지하며 재검토.
- 호냥이보다 캠프 미사일이 적을 더 많이 처치한 느낌.
- 현재보다 게임이 더 구체적으로 구현된 다음 추가 평가 필요.

## 후속 검토 방향(기획 해석/미확정)
- 입력 유지 전진 대신 자동 전진을 우선 시험. 호냥이/캠프 동기 이동과 웨이브 전투 정차 규칙의 관계는 별도 설계 필요.
- 호냥이 기본 공격의 사거리/높이/발사 주기와 적 원거리 사거리 비교. 적의 일방적 선공·대기시간 감소 검토.
- 캠프 지원과 호냥이의 처치 기여도를 구분해 측정. 캠프 단순 약화보다 호냥이 공격의 도달성과 체감 개선을 우선 검토.
- 점프의 회피/공중 타격 역할과 적 판정 개선 실험. 점프 폐기 확정 아님.
- 현 단계에서 적 체력/무기 수치 등을 확정하지 않는다. 이 피드백만으로 자동 전진 세부 로직/공격범위를 임의 확정하지 않는다.

지금 요청은 참고 저장 후 다음 기획 진행이다. Claude에 즉시 수정 지시를 보내지 않았다. 다음 전달 시 이 문서 포함.
