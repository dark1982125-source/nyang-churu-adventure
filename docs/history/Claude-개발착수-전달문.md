# Claude 개발 착수 전달문

아래는 《냥냥 츄르 대모험》의 현재 승인된 기획입니다. 기존 프로젝트와 코드를 먼저 확인한 다음, 확정된 범위로 실제 구현을 진행해 주세요. 기존 작업을 덮어쓰거나 새 프로젝트로 교체하지 말고 사용 중인 엔진·구조에 맞춰 이어가 주세요.

## 1. 먼저 읽을 문서와 우선순위

첨부 문서:
1. `현재-개발기준.md`: 최신 전투 규칙과 충돌/미정 목록. 최우선.
2. `무기-6종-기획정리.md`: 무기별 기본 공격·5개 전용 기술·제작/강화/획득처.
3. `냥냥츄르-최신결정사항.md`: 전체 결정 이력. 최신 18절 우선, 과거 폐기안 구현 금지.

충돌 시 사람에게 임의로 규칙을 바꾸어 제안하기 전에 최신 기준을 적용하세요. 문서에 없는 수치는 테스트용 데이터로 분리하고 임시임을 표시하세요. 새 엔진·새 아트 스타일·새 경제 구조로 전환하지 마세요.

## 2. 가장 중요한 최신 변경

- 2D 횡스크롤, 호냥이 수평 이동은 오른쪽 전진만. 왼쪽 이동·후퇴·대시 없음.
- 점프·자동 기본 공격·자동 전용 스킬·수동 궁극기 유지. 공격은 오른쪽 전방 기준.
- 챕터마다 처치 대상 수가 정해져 있고 모두 처치해야 클리어. 거리 도달만으로 완료 금지.
- 챕터 하나가 한 판, 3웨이브. 각 끝은 엘리트 1/엘리트 2/챕터 보스.
- 캠프는 전진하고 웨이브 전투 때 정차. 플레이어 자동 전진 여부/멈춤 입력은 미정이므로 현재 구현을 확인하고 구현 선택지를 보고하세요. 테스트가 필요하면 ‘전진 입력 시 오른쪽 이동, 입력 없으면 정지’를 임시 옵션으로 분리할 수 있으나 확정 기획으로 기록하지 마세요.
- 적이 뒤에 남아 클리어 불가능해지는 구조는 금지. 첫 테스트는 전방 스폰·전방 전투 구역으로 제한하고, 적이 플레이어를 통과하거나 화면 밖으로 이탈하는 경우 감지·기록하세요. 적을 도주 처리하거나 자동 처치로 집계하는 규칙은 임의로 추가하지 마세요.
- 좌우 조이스틱·대시 버튼/선택지/기력 잔량 예약·대시 장비 효과는 제거/비활성. 회피 스탯 자체는 폐기된 것이 아닙니다.

## 3. 현재 착수할 구현 — 작은 완성 구간 우선

### A. 기존 구현 점검
코드/에셋/저장 구조를 살펴 완료·수정 필요·미구현을 구분하세요. 원격 프로젝트에 현재 에셋이 없다면 임시 표시물을 사용하고 다운로드나 경로가 연결되었다고 가정하지 마세요.

### B. Ch 1의 3웨이브 호위 루프
- 오른쪽 전진·점프·기본 자동 공격.
- 호냥이 HP·냥기력·캠프 멘탈 게이지. HP 또는 캠프 게이지 0 패배.
- 일반 적: 먼지 슬라임/삐죽 풀벌레/운석 쥐.
- 1웨이브 끝 돌돌 운석쥐, 2웨이브 끝 왕먼지 슬라임, 3웨이브 끝 쿵쿵 돌발바닥.
- 웨이브 데이터에 적 수/스폰/엘리트/보스를 설정하고 생존·대기 적이 남으면 다음 웨이브/클리어로 넘어가지 않게 관리.
- 왕먼지 슬라임 분열은 생성한 자식까지 추적하는 기술적 구조를 준비하되, 최종 처치 수 UI 집계 정책은 미정. 소환/분열 적이 무한히 늘거나 자식이 남은 채 완료되는 문제 방지.
- 보스 충격파·돌 투척 등 최신 Ch 1 패턴. 대시 없이 이동·점프·기본 공격으로 대응 가능해야 함.
- 공격력/적 수/속도/드롭량 등 미정 수치는 설정 데이터로 분리해 테스트.

### C. 동료 구출과 판 정산
- Ch 1 시작 먼 곳의 불투명 감옥 표시, ‘동료 발견’ 목표. 개방 전 정체 비공개.
- 모든 필수 적과 보스 처치 → 열쇠 → 감옥 개방 → 코숏 이름/구출 성공 공개 → 캠프 합류.
- 새 동료의 클리어 전 임시지원 없음. 실패 시 신규 구출 미확정, 기존 구출은 유지.
- 재화/제작 재료/설계도는 실패에도 보존, 임시 레벨/스킬은 종료 초기화.
- 저장 상태와 판 상태를 분리, 보상/열쇠/클리어가 중복 지급되지 않도록 처리. 앱 종료 중 정산 정책은 미정이므로 현재 저장 방식과 쟁점을 보고.

### D. 경험치와 선택창
- 작은 개다래: 호냥이 경험치. 작은 톱니: 캠프 경험치. 각자 3지선다.
- 호냥이 기본 공격 1종 별도, 전용 5종 중 최대 3종. 기본 공격은 무소모·임시 강화 가능·등급 진화 없음(최대 레벨 임시 데이터).
- 전용 슬롯이 차면 미보유 전용 스킬 후보 제외. 대시 후보 없음.
- 일반 Lv.1~3 → 유니크 Lv.1~3 → 전설. 유니크 직접 획득은 Lv.1, 전설은 최종 완성.
- 행운: 영구 기본 + 판 임시. 희귀 스킬·레어 드롭에 영향. 공식/상한/기본 확률 미정, 설정 분리.
- 공통 패시브 보유 한도는 아직 미정. 3칸을 확정 구현하지 않음.
- 동료 구출 후 다음 출격부터 기본 지원 제공, 캠프 선택창으로 판 안 강화. 미래 동료를 초기부터 활성화하지 않음.
- 시작 시 지원은 할아버지 배리어/삐콩이 레이저, 코숏은 Ch 1 구출 후.

### E. 자원·기술 프레임워크
- 기본 공격 무소모. 전용 기술은 기력·쿨타임 모두 준비되어야 발동. 실제 발동 시만 차감·쿨타임 시작.
- 기력 자연 회복. 삼색이 보급은 구출 후, 초기부터 제공하지 않음.
- 궁극기는 별도 공유 게이지, 기술 실제 발동마다 차등 충전. 최대 3종 장착, 공격 광역/단일·방어 감속/튕겨내기·회복 호냥이/캠프 완전회복 총 6종.
- 궁극기 자체 재충전 금지. 기본 공격 포함 여부·6종 구체 효과/충전량은 미정. 우선 인터페이스·데이터/게이지 구조를 준비, 임의의 기술을 확정으로 구현하지 않음.
- 코숏 약/삼색이 보급은 전방 투하→접촉 자동 사용. 뒤로 돌아가 수집하는 동작 없음.
- 볼트는 캠프 저체력 자동 시간차 수리. 얼룩이 위장막 세부 판정 미정. 이들은 후속 데이터 구조만 준비해도 됨.

### F. 저장·성장·UI
- 냥젤리: 호냥이 기본 스탯·행운. 황금 개다래: 패시브/궁극기. 골골기어: 캠프 영구 성장.
- 구체 트리 노드는 미정. 저장/노드/조건/가격 데이터 구조와 제한된 테스트 노드를 만들되 최종 트리 창작 금지.
- 다시냥 방울: HP 0 자동 소모, 최대 HP 50%, 3초 무적, 판당 1회, 미사용 판 종료 소멸. 캠프 파괴에는 적용 안 됨. 동시 패배 판정 우선순위/추가 드롭 처리는 미정으로 보고.
- 상단 HP/레벨/경험치, 진행도, 재화/메뉴, 캠프 위 멘탈 게이지. 냥기력/캠프 경험치/궁극기 UI는 필요한 정보를 읽게 구성하고 위치는 검토용으로 표시.
- 적 잔여 수/웨이브 상태를 표시할 수 있게 하되 정확한 UI 형태는 검토용.
- 대시 제거 후 전진·점프·궁극기 입력만 정리. PC/모바일 입력 분리, 자동 전진은 임의 확정하지 않음.

## 4. 이후 바로 진행 가능한 공통 시스템

첫 호위 루프가 동작하면 다음 시스템을 연결할 수 있습니다. 순서와 범위는 기존 구현 상태에 맞추되 실제 검증 결과를 보고하세요.

- 무기/스킬/레시피/재료/보상 데이터 구조. 장갑 기본 공격·확정 5종부터 순차 구현, 다른 무기는 플러그인처럼 추가 가능하게.
- 장착 무기 1개·몸통/발 보호구/액세서리 각 1개, 캠프 교체, 코스튬 별도.
- Ch 2 깡깡이 구출 후 대장간 첫 방문 시 장갑/검 설계도. 없는 미래 시설을 초기 개방하지 않음.
- 전 무기 공통 제작·강화 확률·실패 보정·특별 재료 보존. 최신 무기 문서 표 그대로 데이터화.
- 런처는 제작 4종 10/5/5/3, 다른 무기는 3종 10/5/3. 전설 특별 재료는 무기별 1~2종, 누락하지 않음.
- 챕터 일반 완료 시 해당 고난도 해금. 전설 특별 보상은 본편 Ch 8 완료 후 지급. 지정 챕터 반복 보상 각 1개, 행운 미적용.
- 사운드 매니저: BGM/SFX 개별 볼륨·저장·루프·전환·효과음 동시 재생 제한·경고음 우선순위. 실제 음악 파일은 아직 선정/제공되지 않았으므로 있다고 가정하지 않음.

## 5. 아직 구현 판단을 보류할 사항

- 오른쪽 이동의 자동/수동·정지, 적 통과/남겨진 적 회수, 캠프 간격, 소환 적 카운트 규칙.
- 기존 철깡통 기사 후방 약점·컨베이어 왼쪽 이동·블랙홀·천장 기믹의 새 전투 방향 적합성.
- 공통 패시브 한도, 기본 공격 강화 상한, 캠프 스킬 등급/행운 적용, 중복 상위 카드 처리.
- 스킬별 정확한 피해/기력/쿨타임/진화, 6궁극기 수치·명칭·조건.
- 헤진 가죽조각 등 미정 드롭·신규 4지역 적/보스·장비 상세·탐험 수집.
- 츄르 완성 시점·스토리 재료 중도 실패 보존.

미정이더라도 구조 준비·테스트 설정·다른 확정 기능 구현은 계속 진행하세요. 단, 해결에 필요한 핵심 질문을 한 번에 정리해 주고 임시값은 코드/보고에서 구분하세요.

## 6. 아트와 실제 전달 범위

고양이는 통통한 이족보행 2~3등신 파스텔 픽셀 아트. 전투 완전 오른쪽 측면, 캠프/장비 화면 정면 허용. 투명 스프라이트·일관된 픽셀 윤곽. 걷기 팔/다리 반대 흔들림·머리/몸통 상하 움직임, 얼굴 변형 금지.

현재 설정화는 완성 스프라이트가 아닙니다. 모션/장비 레이어·크기·반측면·광채 보정이 필요합니다. 기존 탑다운 배경은 참고만 하고 횡스크롤 배경을 사용하세요. 전달받지 않은 에셋은 임시물로 명시하고 콘셉트 시트를 그대로 애니메이션이라고 주장하지 마세요.
