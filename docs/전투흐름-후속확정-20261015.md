# 전투 흐름·선택창·정산 후속 확정 — 2026-10-15

이 문서는 이전 전달 후 새로 확정된 변경으로, 상충하는 기존 ‘예정된 모든 잡몹 전멸’·조작 미정·보상 TEMP보다 우선한다.

## 1. 조작과 이동
- 입력 중 오른쪽 전진, 놓으면 정지. 호냥이와 캠프는 함께 움직이고 함께 멈춤, 일정 간격 유지. 캠프는 지상 유지.
- 웨이브 정차 중 함께 전진 정지, 점프·공격·궁극기 가능.
- 적은 점프 중에도 호냥이를 완전히 지나쳐 뒤에 남지 않음. 호냥이도 적을 뛰어넘어 뒤에 남기지 않음.
- 왼쪽 후퇴·대시 없음. 자동 전진/점프 통과/후방 레이저는 확정 기본 규칙에서 제외(비교 개발 도구로 보존 가능).

## 2. 웨이브 — 이전 유한 잡몹 전멸 규칙 대체
- 3웨이브, 끝은 엘리트 1/엘리트 2/보스.
- 일반 구간: 잡몹은 목표 달성 전 계속 생성. 무한 생성은 동시 무한 개체라는 뜻 아님; 동시 수/간격 TEMP 데이터로 제어.
- 지정 처치 수 달성 즉시 잡몹 스폰 중단, 남은 잡몹은 필드에서 제거. 제거 개체는 처치 수·보상 미지급.
- 이후 해당 엘리트/보스 등장. 이 구간에서는 본체와 분열·소환체 전부 처치해야 다음 웨이브/전투 완료.
- 소환/분열 횟수 제한으로 종료 가능성 보장. 정확한 패턴 수치는 미정.
- 일반 구간 목표 카운트와 엘리트/보스 부하 잔여 카운트 구분. 숫자 표시 형식은 아직 미정.
- 잔여 잡몹 정리 시 기존 드롭·장판·투사체를 함께 없앨지는 미정. 잔여 적 제거 보상 금지와 이미 정당하게 생성된 드롭 삭제를 혼동하지 말 것.
- 구출 챕터: 마지막 전투 후 열쇠 → 감옥 개방 → 이름 공개/구출 성공 → 완료.

## 3. 패배·중도 종료
- 캠프 HP 0이면 호냥이 HP·방울 유무와 관계없이 패배. 동시 HP 0도 캠프 파괴 우선, 방울 미발동. 미사용 방울은 판 종료 소멸.
- 앱 도중 종료: 수집한 영구 재화·제작 재료·설계도 보존, 판 종료 후 재접속 캠프 복귀. 이어하기 없음, 웨이브 1부터 재도전.
- 임시 경험치/레벨/스킬/패시브/미사용 방울 초기화, 미완료 신규 구출·클리어 보상 없음.
- 자동저장 주기·갑작스러운 종료의 원자적 정산은 구현 설계 대상. 명시적 종료 이벤트만 의존하지 말 것. 중복 지급·손실 방지 필요.
- 클리어 직전 필드에 남은 드롭의 자동 회수 여부는 미정. 중도 종료는 이미 수집한 자산만 보존.

## 4. 기본 공격·캠프 강화·대체 보상
- 기본 공격 Lv.1 시작, 최대 Lv.5, 등급 진화 없음. 최대면 후보 제외. 판 종료 초기화, 무기 영구 강화 유지.
- 캠프: 구출된 전투 지원 동료 모두 기본 지원 활성, 슬롯 한도 없음. 전투지원 없는 나비/깡깡이에게 임의 기술 추가 금지.
- 각 지원 판 안 임시 강화 최대 Lv.5, 최대면 후보 제외. 영구 골골기어 진화와 별개.
- 호냥이 후보 부족 칸: 냥젤리/HP 즉시 회복/기력 즉시 회복. 성장 가능한 후보 먼저, 부족한 칸만 보충. 슬롯 소모 없이 즉시 적용.
- 캠프 후보 부족 칸: 골골기어/캠프 멘탈 즉시 회복 두 종류만. 기력 보상 없음.
- 수량/회복량·두 종류로 세 칸을 채우는 중복 표시 정책은 미정, 임시값 구분.

## 5. 선택창 일시정지
- 초과 경험치 유지, 다중 레벨업마다 선택 기회 제공.
- 동시 레벨업: 호냥이 선택부터, 이후 캠프. 각 선택 뒤 현재 보유/레벨 반영해 다음 후보 생성.
- 모두 선택 후 전투 재개. 적/피해/투사체/회복/쿨타임/궁극기 충전 등 전투 시간 함께 정지. 선택의 즉시 보상 자체는 적용.
- 초기 버전 새로고침/건너뛰기 없음. 세 후보 중 하나 선택. 추후 기능 추가 검토.

## 6. 보급품
- 약·캡슐·츄르는 접촉/흡인 도착 시 즉시 소모, 필요 없는 상태에도 별도 저장하지 않음. HP/기력 상한 초과하지 않음, 상태이상 없으면 정화 효과 없음.
- 다시냥 방울은 별도 부활 보유 아이템. 이미 보유/부활 소진 후 추가 획득 처리 미정.
- 보급 타이밍·기간·수치 미정.
