# 캠프 보상·전투 전환·클리어 처리 확정

확정일: 2026-10-15. 아래 항목은 이전 문서의 동일 항목 및 미정 표시보다 우선한다. 이외 기존 규칙은 유지한다.

## 1. 전투 중 캠프 레벨업
- 골골기어 영구 스킬트리와 별개인 해당 판 임시 강화다.
- 강화 가능한 서로 다른 기술을 우선 표시한다. 3개 이상이면 3개, 2개면 기술 2개+대체 보상 1개, 1개면 기술 1개+대체 보상 2개다.
- 대체 보상은 골골기어 획득과 캠프 체력 즉시 회복 두 종류다. 기술이 모두 최대라면 이 두 종류만 표시한다.
- 유효 선택지가 2개면 카드 2장만 표시한다. 같은 보상을 중복하거나 혼합 보상을 새로 만들지 않는다.
- 캠프 체력 최대 시 회복 카드를 제외한다. 골골기어만 남으면 선택창 없이 자동 지급한다.
- 이는 일반적인 레벨업 대체 보상이며 볼트의 수리 기술과 별개다. 지급량/회복량은 TEMP 및 플레이 테스트 조정 대상이다.

## 2. 일반 구간에서 엘리트·보스전 전환
- 목표 처치 수 달성 즉시 일반 몬스터 생성 중단, 남은 일반 몬스터 보상 없이 제거한다.
- 적 투사체·공격 장판과 호냥이/캠프의 진행 중 공격을 제거한다.
- 보호막·버프와 남은 쿨타임은 그대로 유지한다. 쿨타임 초기화/즉시 재사용을 제공하지 않는다.
- 드롭 아이템을 자동 회수한다. 회수 경험치에 따른 선택을 처리한 뒤 짧은 등장 연출로 넘어간다.
- 등장 연출 동안 전투 시간·쿨타임·지속시간 등 전투 타이머를 함께 정지한다.

## 3. 구간별 경험치와 챕터 종료
- 일반 구간→엘리트/보스: 자동 회수와 레벨업 선택 완료 후 등장 연출.
- 엘리트 및 필수 소환/분열 개체 처치→다음 웨이브: 레벨업 선택을 처리한 뒤 진행.
- 챕터 마지막 보스와 필수 소환/분열 개체가 모두 처치되면 클리어 상태를 먼저 확정하여 호냥이·캠프 레벨업 선택을 종료한다.
- 이후 남은 아이템 자동 회수 및 재화/재료 정상 정산. 전투 경험치는 다른 재화로 환산하지 않고 종료한다. 대기 중인 임시 강화 선택도 띄우지 않는다.
- 구출 챕터는 열쇠/감옥 개방·동료 공개·구출 성공 연출을 거쳐 결과 화면으로 이동한다.
