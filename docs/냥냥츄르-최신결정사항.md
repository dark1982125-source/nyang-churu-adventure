# 냥냥 츄르 대모험 — 최신 결정사항

> 2026-10-15 우선 안내: 오른쪽 전진 전용·대시 폐기·지정 적 전부 처치 조건으로 변경. 현재 기준은 `현재-개발기준.md`, 최신 무기 표는 `무기-6종-기획정리.md`를 우선 참조. 아래 1~17절은 과거 결정 이력을 포함하므로 후속 18절과 충돌하면 18절 우선.

정리일: 2026-10-14. 이전 통합 기획서를 보완하는 최신 변경 기록. 충돌 시 이 문서의 명시적 확정사항을 우선한다. 제안과 미정은 확정으로 취급하지 않는다.

## 1. 진행·패배·구출 확정 규칙

- 챕터 하나가 한 판(Run), 챕터마다 3개 웨이브.
- 웨이브 1 끝: 엘리트 1. 웨이브 2 끝: 엘리트 2. 웨이브 3 끝: 챕터 보스.
- 캠프는 오른쪽으로 전진하고 웨이브 전투에서 정차한다.
- 임시 스킬은 세 웨이브 동안 유지, 판 종료 시 초기화. 재도전은 웨이브 1부터.
- 호냥이 HP 0이면 패배. 희귀 부활 아이템을 획득했다면 부활 가능.
- 캠프 멘탈 게이지 0이면 패배. 호냥이 부활 아이템과 별개.
- 실패해도 획득한 영구 재화는 보존. 새 동료는 구출되지 않음. 이전에 구출한 동료는 유지.
- 클리어 전 새 동료의 임시지원 없음.

### 구출 챕터의 최신 연출

1. 챕터 진입 시 저 멀리 불투명한 감옥 상자 표시.
2. ‘동료 발견! 보스를 물리치고 감옥 열쇠를 획득하세요.’ 목표 안내.
3. 웨이브 1·2의 엘리트 돌파. 동료의 이름·초상·직업 단서는 공개하지 않음.
4. 마지막 웨이브 보스 처치 후 감옥 열쇠 획득.
5. 호냥이가 열쇠로 감옥 상자를 직접 개방.
6. 동료 등장과 함께 이름 공개, ‘닥터 코숏을 구출했습니다!’ 등 성공 문구.
7. 챕터 완료·캠프 복귀 후 정식 합류, 시설과 지원 해금. 다음 도전부터 활용.

‘엘리트 처치 후 구출’, ‘상호작용 후 탈출 준비’, ‘클리어 전 임시지원’은 폐기한다. 구출 챕터에서는 보스 처치만으로 완료 화면을 열지 않고 감옥 개방까지 마무리한다. 비구출 챕터의 종료 처리와 중단·저장 예외는 상세화 대상.

## 3. 재화·영구 성장

| 자원 | 용도 |
|---|---|
| 작은 개다래 열매 | 전투 경험치, 임시 3지선다 성장 |
| 냥젤리 | 호냥이 체력·공격력·회피·방어 스킬 영구 레벨업 |
| 황금 개다래 | 호냥이 새 패시브·궁극기 영구 해금과 레벨업 |
| 골골기어 | 호냥이와 별도인 이동캠프 영구 스킬트리 |

누적 개다래 재화 명칭은 황금 개다래로 변경. 노드·비용은 추후 논의. 장비 제작 재화는 미정.

## 4. 임시 스킬·대시·궁극기·냥기력

- 경험치 충전 시 일시정지, 무작위 3개 선택지. 공격·방어·지원·이동 혼합, 종류별 1개 보장 아님.
- 대시는 기본 제공이 아니라 선택창에서 획득하는 임시 기술. 수동 버튼 사용을 시험 적용.
- 스킬 중복 선택으로 일반 Lv.1 → Lv.2 → Lv.3 → 유니크 진화하는 방향.
- 낮은 확률로 유니크·전설을 직접 제시하는 행운 방식도 병행. 행운 수치로 빈도 조절.
- 일반 94%·유니크 5%·전설 1%는 확정값이 아닌 이전 테스트 제안.
- 최초 선택 포함 3회 여부, 유니크 이후 성장 단계, 직접 획득 시작 레벨과 중복 처리 미정.
- 수동 궁극기는 영구 스킬트리 조건으로 해금, 별도 게이지 충전 후 직접 발동. 전설 등급 스킬과 별개.
- 스킬에 냥기력 소모·쿨타임을 적용하는 방향 채택.
- 기본 펀치 무소모, 기력 자연 회복, 궁극기·캠프 지원의 기력 제외, 대시 1회분 잔량 보호는 구체 적용 제안이며 상세 수치는 미정.

## 5. 동료 역할 최신 변경

| 동료 | 기본 역할 | 전투 관련 |
|---|---|---|
| 수염할아버지 | 캠프 관리·고서 해독·이야기 해설 | 골골송 배리어 |
| 삐콩이 | UI·무전·전투 가이드 | 서치 레이저 |
| 닥터 코숏 | 주치의, 체력·상태이상 치료 | 응급 처방 상세 발동/대상 미정 |
| 셰프 삼색이 | 냥기력 보급·음식 버프·전설의 츄르 연성 | 기존 HP 보급 중심에서 변경 |
| 얼룩이 | 탐험 자동 수집·보급품 탐색 | 대표 지원: 캠프 위장막 |
| 나비 | 호냥이 보호장비 제작·강화, 코스튬 | 전투지원 제외, 캠프 수리 역할 폐기 |
| 엔지니어 볼트 | 캠프 수리·개조·골골기어 스킬트리 업그레이드 | 응급수리 상세 미정 |
| 대장장이 깡깡이 | 공격 장비 제작·강화 | 직접 지원 없음이 현재 제안 |

얼룩이 위장막의 지속·무적 여부·기존 투사체 판정은 개발 중 논의. 캠프 이동속도 강화는 보조 후보로 남김. 탐험의 냥젤리·골골기어 기본 수집, 황금 개다래 희귀 보상은 제안. 코숏 시설의 진료소·연구 메뉴 관계 미정.
나비는 하얀 단모 고양이 최신 외형, 호냥이는 머리 꼬리 오류를 제거한 청록 스카프 이족보행 외형. 볼트·깡깡이 외형은 제안만 있고 이미지 미제작.

## 6. 유지되는 이야기·아트 방향

- 저주로 흉폭해진 멘탈랩터를 전설의 츄르로 치유, 원래 순한 거대 고양이로 회복. 참깨·주민들도 치유.
- 전투 측면, 캠프·장비 UI 정면 허용, 통통한 2~3등신 파스텔 픽셀 아트.
- 걷기 팔·다리 교차, 머리·몸통 상하 움직임, 얼굴 형태 유지.
- 게임용 스프라이트 투명 배경·텍스트 없음. 현재 설정화는 완성 에셋이 아니며 픽셀 규격·광채·각도·장비 레이어 보정 필요.
- 기존 배경은 소재·색감 참고, 실제 횡스크롤 배경은 재제작.

## 7. 이전 저장 시점의 미정 목록 — 아래 후속 결정으로 갱신됨

1. **부활 아이템:** 발동 방식, 회복량, 무적 시간, 중복 보유, 미사용 아이템 판 종료 처리. 영구 부활 노드와의 관계.
2. 스킬 성장 횟수·등급 처리·행운 확률·궁극기 게이지 충전.
3. 냥기력 소비·회복·자동 스킬과 대시 우선순위.
4. 동료 세부 능력·시설·탐험 정책·장비 제작.
5. 핵심 재료 실패 보존 여부·츄르 완성 시점·레시피와 액티베이터 관계.
6. 신규 챕터 적/보스, 웨이브 길이, 기존 모호한 패턴 판정과 캠프 이동 규칙.

수치와 노드 상세는 개발하면서 논의한다. 예전 통합본은 배경 자료로 보존하고, 이 변경본과 함께 개발진에게 전달한다.

## 8. 후속 확정사항 — 이번 저장의 최신 기준

이 절은 앞 절에 남아 있는 이전 미정·제안을 대체한다. 15챕터 배치·보스 열쇠 구출 규칙·실패 시 재화 보존 등 변경 없는 사항은 유지한다.

### 부활: 다시냥 방울
- 희귀 아이템 ‘다시냥 방울’: 금빛 고양이 방울, 분홍 하트 문양, 민트 리본.
- 보유 시 호냥이 HP 0에서 자동 소모해 최대 HP의 50%로 부활, 3초 무적.
- 한 판에 부활 1회, 미사용 아이템은 판 종료 시 소멸.
- HP 옆 보유 아이콘, 획득·부활 방울 효과음 연출.
- 캠프 파괴에는 적용되지 않음. 중복 드롭 처리·영구 부활 노드 존치 여부는 미정.

### 스킬 등급과 행운
- 일반 Lv.1 → Lv.2 → Lv.3 → 유니크 Lv.1 → Lv.2 → Lv.3 → 전설.
- 최초 선택이 일반 Lv.1, 다음 중복 선택마다 한 단계 상승하는 정리안 채택.
- 일반 보유 중 유니크 직접 획득 시 유니크 Lv.1로 승급. 유니크 신규 획득도 Lv.1 시작.
- 전설 직접 획득 시 중간 단계 없이 최종 완성. 전설은 추가 레벨업 없음.
- 완성한 전설 스킬의 추가 강화 카드는 목록에서 제외하는 안. 낮은 등급 카드의 처리, 동일 등급 직접 획득 처리는 미정.
- 행운은 유니크/전설 선택지와 레어 아이템 드롭 모두에 영향.
- 기본 스탯 트리의 영구 행운은 냥젤리로 강화. 호냥이 전투 3지선다의 임시 행운은 판 종료 초기화.
- 적용 행운 = 영구 기본 행운 + 임시 행운. 확률·상한·증가량은 미정.
- 필수 감옥 열쇠·스토리 재료는 확정 보상 유지 제안, 행운으로 진행을 막지 않음.

### 호냥이/캠프 경험치와 선택창 분리
- 호냥이: 작은 개다래 열매 → 호냥이 경험치 → 호냥이 3지선다.
- 캠프: 작은 톱니 → 캠프 경험치 → 캠프/동료 지원 3지선다.
- 작은 톱니는 은회색 단순 톱니, 영구 재화 골골기어는 금빛·민트 코어로 구분하는 시각안.
- 기존 호냥이와 캠프를 한 창에 섞는 구조는 폐기.
- 양쪽 임시 강화는 판 종료 초기화. 경험치 드롭량·요구량·동시 레벨업 처리·UI 위치는 미정.
- 캠프 선택에도 동일 희귀 등급 구조·호냥이 행운을 적용할지는 아직 명시되지 않음.

### 냥기력
- 기본 냥냥 펀치 무소모 자동 공격.
- 추가 자동 스킬: 냥기력 충분·쿨타임 완료 시 발동, 실제 발동 때 차감·쿨타임 시작. 부족하면 대기.
- 대시: 수동, 냥기력·쿨타임 사용. 자동 스킬은 대시 습득 시 대시 1회분 기력을 보존하는 규칙 채택.
- 궁극기: 별도 게이지만 소비. 캠프 지원은 호냥이 기력 미소모·지원별 쿨타임.
- 기력 자연 회복 + 삼색이 보급. 소비량·회복량·주기 등 수치는 개발 중 조정.
- 새 무기들의 기본 공격도 무소모로 할지는 기존 펀치 규칙을 확장해 별도 명시할 필요 있음.

### 궁극기
- 총 6종: 공격(광역/단일), 방어(감속/튕겨내기), 회복(호냥이 완전회복/캠프 완전회복).
- 개별 영구 해금·강화는 황금 개다래 사용. 캠프에서 최대 3종 장착.
- 게이지 공유, 가득 차면 장착 기술 중 하나를 수동 발동하고 게이지 소비.
- 충전은 피해량이 아니라 호냥이의 스킬 실제 발동 기준. 스킬별 충전량 차등, 다단히트라도 1회 발동 기준.
- 궁극기 자체는 재충전하지 않음. 기본 공격·대시 포함 여부는 미정.
- 웨이브 사이 게이지 유지·새 판 0 시작은 이전 제안. 구체 구현 시 확인.
- 공격형은 호냥이 앞에서 전방 발사. 광역은 여러 적 HP 피해, 단일은 집중 HP 피해.
- 밀쳐내기는 HP 피해와 별개이며 역할 분류 후 방어 궁극기로 분리.
- 회복 궁극기는 별도 긴 쿨타임, 체력 0 이전 사용. 부활은 다시냥 방울 담당.
- 명칭·정확한 효과·방향(바라보는 방향/진행 방향)·해금 조건·수치는 미정. 젤리 대포·별똥 젤리포는 후보이며 확정 6종과 효과 재정렬 필요.

### 동료 기본 지원과 진화
- 정식 구출 후 다음 출격부터 기본 지원 자동 제공. 캠프 선택 운에 따라 기본 능력이 사라지지 않음.
- 골골기어 영구 트리 일정 레벨에서 기술 이름·외형·기본 효과 진화, 이후 다시 레벨업.
- 작은 톱니 캠프 3지선다는 해당 판 지원 강화.
- 코숏 HP 기술명 ‘캣닢 캡슐’: 캡슐 개방·캣닢가루 회복 연출.
- 코숏 상태이상 기술명 ‘개다래 정화약’: 약병 형태, 치료 대상·수치는 미정.
- 코숏 약과 삼색이 기력 보급은 호냥이 전방의 바닥에 자동 투하, 호냥이가 접촉하면 자동 사용.
- 자동 직접 치료/멀리서 적용하는 방식은 전방 보급 방식으로 변경. 투하 거리·발동 기준·유지 시간·수집 범위·이동 불가 상태 처리 추후 논의.
- 삼색이 ‘활력 츄르’와 진화 이름들은 아직 후보.
- 볼트: 캠프 체력이 일정 비율 이하이면 자동 응급수리, 시간에 걸친 소량 복구 후 쿨타임. 영구·임시 강화 적용, 기준·수치 미정.
- 얼룩이 위장막·나비 비전투 보호장비 제작·깡깡이 공격 장비 제작 유지.

### 장비와 무기
- 장비 슬롯 제안: 공격 1/몸통 보호 1/발 1/액세서리 1, 코스튬 별도. 정확한 슬롯 구성은 미확정.
- 무기 후보: 장갑/검/망치/창/마법봉/발사기. 모든 종류 제작 확정으로 간주하지 않음.
- 공격 스킬 선택은 장착 무기에 맞춤. 공통 이동·방어·행운과 캠프 창은 별도.
- 털실공·캣닢 폭탄은 발사기 전용. 다른 무기 장착 시 선택창에 나오지 않음.
- 기본 장갑으로 시작. 깡깡이 구출 후 다른 무기 순차 제작·해금.
- 캠프에서 무기 1개 장착, 판 중 교체 없음. 판 종료 시 제작 무기는 유지, 임시 스킬 초기화.
- 장비 제작/강화에는 냥젤리를 쓰지 않음. 설계도로 제작법 해금, 실제 제작 재료를 소모하는 구조 채택.
- 나비 보호장비에도 같은 원칙, 천/실 등 재료를 쓰는 방향.
- 냥철 조각·별빛 결정·젤리패드·생선뼈·털실 등은 재료 후보. 종류·조합·수량·획득처는 미정.
- 설계도 1회 등록 영구 유지·제작 재료 실패 보존은 제안이며 아직 개별 확정 전.

## 10. 장비 제작·구출·강화 후속 결정 — 최신 우선 기준

정리일: 2026-10-14. 이 절은 앞 절의 구출 배치·제작 담당·장비 미정 기록과 충돌할 때 우선한다. 기존 보스 열쇠 획득 → 감옥 개방 → 동료 정체 공개 → 정식 구출 규칙은 유지.

### 10.1 수정 확정한 구출 배치

| 챕터 | 동료 | 해금 기능 |

### 10.2 장비 슬롯·제작 담당

- 무기·몸통 보호구·발 보호구·액세서리 각 1칸 확정.
- 성능 장비는 캠프에서만 교체. 코스튬은 성능과 별도 관리.
- 전투 외형은 무기부터 반영하고 나머지는 단계적 추가.
- 다시냥 방울은 소비 아이템, 장비 슬롯을 차지하지 않음.
- 깡깡이: 무기·몸통 보호구·발 보호구 제작. 나비의 보호구 제작 역할을 이전.
- 나비: 액세서리·코스튬 제작, 전투 지원 없음.
- 제작·강화는 설계도와 실제 제작 재료 사용, 냥젤리 비용 없음.
- 설계도 등록 후 제작법 유지, 재료·설계도는 챕터 실패에도 보존.

### 10.3 제작품 목록 — 승인한 방향과 이름 후보

보호구 후보: 폭신 누빔 조끼(방어), 튼튼 젤리 갑옷(체력), 방수 탐험 코트(독/지속 피해 저항), 온기 방한 조끼(빙결 시간 감소).
발 보호구 후보: 사뿐 발 보호대(이속), 슝슝 대시 부츠(대시 기력 절감), 눈길 발톱 부츠(미끄럼/지형 둔화 저항), 내열 발바닥 신발(뜨거운 바닥 피해 감소). 대시 장비는 대시를 해금하지 않음.

### 10.4 재료 획득 원칙

- 챕터·필드 몬스터별로 드롭 재료를 배치, 특정 장비 핵심 재료는 특정 챕터 전용으로 지정 가능.
- 한 재료가 반드시 한 몬스터에게서만 나오지는 않음. 성격이 맞는 여러 몬스터에게서 드롭 가능.
- 일반 몬스터는 제작 재료, 엘리트·보스·보물상자는 상위 재료/설계도 획득처 방향.
- 클리어 챕터 재도전으로 재료 수집 가능. 실패해도 제작 재료와 설계도 보존.
- 탐험이 미도달 챕터 재료를 얻지 못하게 제한하는 안·챕터 전용 재료를 탐험으로 얻을지 여부는 미정.

### 10.5 젤리 펀치 장갑 — 제작 확정

기본 지급 장갑과 별도의 제작품. 설계도는 Ch 2 깡깡이 구출 완료 보상, 제작 재료는 Ch 1~2에서 전부 획득 가능하게 배치.

| 제작 재료 | 수량 | 역할 |
|---|---:|---|
| 말랑 젤리덩이 | 10 | 타격 패드 |
| 헤진 가죽조각 | 5 | 장갑 본체 |
| 낡은 털실뭉치 | 3 | 봉합·손목 끈 |

- 말랑 젤리덩이: Ch 1 먼지 슬라임·Ch 2 젤리 방울 등.
- 단단젤리: Ch 1 웨이브 2 엘리트 왕먼지 슬라임, Ch 2 웨이브 2 엘리트 젤리 집게왕, Ch 2 보스 푸딩포식자.
- 단단젤리는 장갑 영구 강화용 상위 젤리 재료.
- 가죽·털실의 정확한 드롭 몬스터는 미정. 운석 쥐·삐죽 풀벌레는 후보일 뿐 고정하지 않음.
- 몬스터별 확률·드롭 개수는 미정.

### 10.6 젤리 펀치 장갑 — 강화·진화 확정

- 공격력 중심 영구 강화, 누적 표기 +0~+10.
- +5 성공 시 유니크, +10 성공 시 전설로 진화. 이전 ‘등급별 +0 재시작’ 표시 대신 누적 +수치 사용.
- 성공 후 별도 진화 추첨 없음. 기존 공격력 보존, 전투 스킬 등급과 별개.
- 높은 강화 단계일수록 실패 확률이 증가하는 방향.
- 실패 시 무기·강화 단계 보존, 기본 재료만 소모. 특별 재료는 실패 시 보존·성공 시 소모.
- 연속 실패 보정·확정 성공 상한·진행 저장·화면 표시 방향 채택. 보정 수치와 최대 횟수는 미정.

| 목표 단계 | 시도당 단단젤리 | 성공 시 소모할 특별 재료 |
|---|---:|---|
| +1 | 5 | 없음 |
| +2 | 5 | 없음 |
| +3 | 8 | 없음 |
| +4 | 8 | 없음 |
| +5 — 유니크 진화 | 15 | 윤기나는 가죽 1개 |
| +6 | 17 | 없음 |
| +7 | 20 | 없음 |
| +8 | 23 | 없음 |
| +9 | 27 | 없음 |
| +10 — 전설 진화 | 35 | 황금빛 털뭉치 1개 |

위 재료 수량은 사용자 승인한 초기 설정. 드롭량과 함께 플레이 테스트로 조정 가능. 특히 유니크 구간 +6 이후 요구량은 이전 단계보다 줄이지 않는다.

- 윤기나는 가죽: 정확한 획득처 미정.
- 황금빛 털뭉치: 고난도 콘텐츠 획득 방향 확정, 모드·챕터·몬스터 미정.
- 왕젤리 핵·별빛 젤리 심장 안은 폐기.

### 10.7 아직 확정되지 않은 강화 수치 제안

이전 성공률 표를 누적 단계로 환산하면 +1 100%, +2 100%, +3 90%, +4 80%, +5 70%, +6 100%, +7 100%, +8 60%, +9 30%, +10 10%이다. 이 표는 제안으로 남긴다. +6·+7에서 성공률이 다시 높아지는 것이 ‘단계가 높을수록 실패율 상승’ 방향과 맞는지 재검토 필요. 마지막 10%/5%도 최종 확정 전이며, 보정 포함 실제 재료 부담을 검토한다.

공격력 제안은 +0 무기 공격력 기준 합산: +1~+4 각각 +5%, +5 +15%, +6~+9 각각 +5%, +10 +25%. 누적 +5는 +35%, +10은 +80%. 수치 명시적 확정은 아니며 호냥이 총 공격력과의 계산식 미정.

## 11. 이전 논의 목록 — 아래 후속 확정사항으로 갱신

1. 강화 성공률·실패 보정/확정 성공 상한·공격력 증가량.
2. 윤기나는 가죽·황금빛 털뭉치 획득처와 고난도 콘텐츠 해금.
3. 일반/엘리트/보스 재료 드롭 확률·개수, 가죽·털실 드롭 분배.

## 12. 강화·재료 보상·고난도 최종 후속 결정

정리일: 2026-10-14. 아래 내용은 앞 절의 성공률 후보, 특별 재료 희귀 드롭안, 고난도 해금 미정 기록을 대체한다. 수치는 승인된 초기 설정으로, 추후 플레이 테스트 조정 가능.

### 12.1 젤리 펀치 장갑 강화 기준표

확정 성공률 표는 순차 감소 수정안을 기준으로 한다. 이후 실패 보정량을 +5%포인트로 확정했다. 모든 단계는 도달하려는 목표 단계이며, 시도 횟수가 아니다.

| 목표 | 기본 성공률 | 시도당 단단젤리 | 특별 재료 | 성공 시 공격력 추가 |
|---|---:|---:|---|---:|
| +1 | 100% | 5 | 없음 | +5% |
| +2 | 100% | 5 | 없음 | +5% |
| +3 | 90% | 8 | 없음 | +5% |
| +4 | 80% | 8 | 없음 | +5% |
| +5 — 유니크 진화 | 70% | 15 | 윤기나는 가죽 1개 | +15% |
| +6 | 60% | 17 | 없음 | +5% |
| +7 | 50% | 20 | 없음 | +5% |
| +8 | 40% | 23 | 없음 | +5% |
| +9 | 25% | 27 | 없음 | +5% |
| +10 — 전설 진화 | 10% | 35 | 황금빛 털뭉치 1개 | +25% |

- 공격력은 +0 무기 공격력을 기준으로 합산. +5 누적 +35%, +10 누적 +80%.
- 기본 공격력 20이면 +5는 27, +10은 36. 호냥이 전체 스탯을 곱하는 수치가 아님.
- 강화는 무작위 추첨, 같은 무기·같은 목표 단계 실패마다 성공률 +5%포인트.
- 같은 단계에서 9회 연속 실패하면 10번째 시도 확정 성공. 적용 확률은 100% 상한.
- 성공하면 해당 단계 실패 기록 초기화. 실패 기록은 저장·유지.
- 현재 확률·실패 횟수·천장까지 남은 횟수를 UI에 표시.
- 실패 시 무기와 강화 수치는 보존, 단단젤리만 소모. 특별 재료는 실패 시 보존하고 성공 시 1개 소모.
- +5/+10 강화 성공 직후 진화하며 추가 진화 추첨 없음.
- 행운 스탯은 강화 확률에 적용하지 않는 기존 제안 유지. 최종 구현 전 명시 확인 대상.
- 무기 등급은 영구, 판 안의 스킬 등급은 임시. 다른 장비에도 같은 강화표를 적용할지는 아직 미정.

### 12.2 단단젤리 획득 범위·드롭 초기 설정

- 초반 기존 대상: 왕먼지 슬라임(Ch 1 엘리트), 젤리 집게왕(Ch 2 엘리트), 푸딩포식자(Ch 2 보스).
- 중후반의 젤리 성격 지정 일반 적·엘리트·보스에도 드롭 추가. 구체 목록 미정.
- 아래 표는 모든 적이 아니라 단단젤리 드롭 대상으로 지정된 적에만 적용.

| 대상 | 드롭 확률 | 획득 수량 |
|---|---:|---:|
| 일반 난도 일반 적 | 10% | 1개 |
| 일반 난도 엘리트 | 100% | 3~5개 |
| 일반 난도 보스 | 100% | 6~8개 |
| 고난도 일반 적 | 15% | 1~2개 |
| 고난도 엘리트 | 100% | 5~8개 |
| 고난도 보스 | 100% | 10~15개 |

- 재료 수집 챕터 한 판 목표: 일반 약 15~25개, 고난도 약 30~45개.
- 출현 수·대상 배치에 따라 목표 획득량을 맞춤. 범위 내 수량 분포는 미정.
- 행운은 일반 적 드롭 확률, 확정 드롭 엘리트·보스의 수량에 영향. 공식·상한 미정.
- 제작 화면에 획득 가능한 챕터/적 안내.

### 12.3 특별 진화 재료 — 확정 클리어 보상으로 변경

특별 재료 희귀 드롭안은 폐기한다. 강화가 이미 랜덤이므로 특별 재료 획득은 지정 도전 성공 보상으로 분리.

| 재료 | 지정 보상 챕터 | 지급 조건 | 수량 |
|---|---|---|---:|
| 윤기나는 가죽 | 일반 Ch 3 가시털 숲 / Ch 6 쉿쉿 모래사막 / Ch 10 안개 발자국 밀림 | 해당 챕터 클리어 | 매 클리어 1개 |
| 황금빛 털뭉치 | 고난도 Ch 3 가시털 숲 / Ch 8 꽁꽁 골골 설원 / Ch 13 악몽 성문 | 본편 Ch 8 클리어 후 해당 고난도 클리어 | 매 클리어 1개 |

- 반복 클리어로 다시 획득 가능, 최초 1회 한정 아님.
- 실패 시 신규 클리어 보상 지급 없음. 이미 보유한 재료는 유지.
- 특별 재료 지급에는 행운 적용 없음, 지급 수량 증가 없음.
- 본편 Ch 8 클리어 이후 이미 열린 고난도 Ch 3를 재도전해도 황금빛 털뭉치 지급.
- 해금 전 클리어의 소급 보상은 명시되지 않았으며 자동 지급으로 간주하지 않음.
- 여러 챕터에 획득처를 두는 방향 확정. 다른 장비 진화에도 공용으로 쓸지 정확한 제작표는 미정.

### 12.4 고난도 모드

- 각 챕터 일반 난도 클리어 시 해당 챕터 고난도 해금.
- 본편 Ch 8 일반 클리어 시 황금빛 털뭉치 보상 자격 해금.
- 고난도도 기존 지역 구성·3웨이브·엘리트 2종/보스 1종 틀 유지.
- 적 체력·공격력 증가.
- 공중·원거리·캠프 집중 공격 적 조합 강화.
- 엘리트·보스 패턴 간격 단축, 일부 패턴 조합 추가.
- 공격 예고·회피 가능한 틈은 유지.
- 고난도 단단젤리 보상 증가 표 적용.
- 이미 완료한 동료 구출을 반복하지 않고 전투·보상에 집중.
- 정확한 배율·편성·추가 패턴·보상 수량 세부는 테스트하며 논의.

## 14. 생선뼈 검·망치 및 공통 무기 규칙 — 최신 추가 기록

정리일: 2026-10-14. 이 절은 앞 절에서 미정이던 다른 무기 강화 규칙의 적용 범위와 생선뼈 검/망치 후보를 갱신한다. 획득처 등 승인 전 제안은 아래에 별도 표시한다.

### 14.1 모든 무기 공통 제작·강화 확정

- 최초 제작 재료 3종: 핵심 10개 / 보조 5개 / 결속 3개. 장갑의 수량을 모든 무기에 적용.
- 공통 재료는 여러 무기·보호구·액세서리에 중복 사용 가능.
- 강화 기본 재료 종류만 무기별로 다름. +1~+10 소모량은 5/5/8/8/15/17/20/23/27/35개.
- 기본 성공률은 100/100/90/80/70/60/50/40/25/10%.
- 같은 무기·목표 단계 실패마다 +5%포인트, 9회 연속 실패 후 10번째 확정 성공, 기록 저장.
- 실패 시 기본 강화 재료만 소모. 무기·강화 단계·특별 재료 보존.
- +5 유니크, +10 전설 진화. 성공 시 특별 재료 소모, 추가 진화 추첨 없음.
- +0 무기 공격력 기준 합산: +1~4 각 +5%, +5 +15%, +6~9 각 +5%, +10 +25%. 누적 +5 +35%, +10 +80%.
- 공격 방식·전용 스킬·기본 공격력·주기·재료/획득처로 무기 차별화.
- 위 규칙은 무기 전체에 확정 적용. 보호구·액세서리의 강화 효과/성공률까지 동일 적용한다고 확정한 것은 아님.

### 14.2 생선뼈 검 공격 구성 확정

- 기본 부채꼴 베기: 전방 짧은 부채꼴 범위 자동 공격.
- 전용 스킬 5종 준비, 한 판 최대 3종 습득하는 초기 구성 채택. 공통 대시/행운·궁극기는 별도 관리.

| 기술 | 효과 방향 |
|---|---|
| 가시베기 | 검에서 불규칙한 가시 모양 광선이 전방으로 뻗어 타격 |
| 냥냥 회오리베기 | 검을 휘두르면 물고기들이 전방 회오리를 만들어 반복 광역 피해 |
| 깜짝 천둥베기 | 검을 휘두르면 전방 적 위치 위에 번개 낙하 |
| 생선뼈 관통베기 | 생선뼈 검기가 전방 직선 관통 |
| 꼬리표 집중베기 | 전방 한 적에 물고기 표식 후 집중 연속 검격 |

범위·냥기력·쿨타임·진화 효과·수치 등은 제작하면서 결정. 전방 발생 원칙 유지.
