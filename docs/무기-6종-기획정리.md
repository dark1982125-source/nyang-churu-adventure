# 냥냥 츄르 대모험 — 무기 6종 기획 정리

정리일: 2026-10-15. 장갑·검·망치·창·마법봉·발사기의 현재 결정사항. 기존 4종 문서에 5·6번째 무기 확정 내용을 추가했다. 미정·후보는 구분 표기하며, 후속 절의 변경이 우선한다.

## 1. 모든 무기 공통 규칙

- 최초 제작 재료 3종: 10개·5개·3개. 냥젤리 비용 없음.
- 캠프에서 무기 1개 장착, 판 중 교체 없음. 기본 장갑 지급, 깡깡이 Ch 2 구출 후 제작 개방.
- 장착한 무기에 맞는 공격 스킬 선택. 스킬 성장·유니크/전설 행운 획득은 해당 판 한정.
- 무기는 영구 보유·강화, 실패해도 유지. 재료·설계도도 도전 실패 시 보존.
- +5 유니크·+10 전설 진화. 강화 성공 후 추가 진화 추첨 없음.
- 강화 실패: 기본 강화 재료만 소모, 무기·강화 단계·특별 재료 보존.
- 실패당 같은 무기·목표 단계 성공률 +5%포인트, 9회 연속 실패 후 10번째 확정 성공. 기록 저장, 성공 시 초기화.
- 특별 재료는 성공 시 소모. 지정 챕터 반복 클리어마다 1개 확정 보상, 행운 미적용.
- 전설용 특별 재료는 본편 Ch 8 클리어 이후 지정 고난도 보상으로 지급.
- 호냥이는 오른쪽으로만 전진하며 후퇴·대시 없음. 모든 공격은 오른쪽 전방 기준.
- 모든 무기: 기본 공격 별도 1개 + 전용 5종 중 최대 3종 습득. 3칸이 차면 새 전용 기술은 선택 목록에서 제외.
- 기본 공격은 냥기력 무소모, 판 안에서 별도 강화 가능. 추가 슬롯을 차지하지 않고 등급 진화 없이 최대 레벨까지 성장. 최대 레벨·수치 미정.

| 목표 강화 | 기본 성공률 | 기본 재료 수량 | 공격력 추가 |
|---|---:|---:|---:|
| +1 | 100% | 5 | +5% |
| +2 | 100% | 5 | +5% |
| +3 | 90% | 8 | +5% |
| +4 | 80% | 8 | +5% |
| +5 | 70% | 15 | +15% |
| +6 | 60% | 17 | +5% |
| +7 | 50% | 20 | +5% |
| +8 | 40% | 23 | +5% |
| +9 | 25% | 27 | +5% |
| +10 | 10% | 35 | +25% |

공격력 보너스는 +0 무기 공격력 기준 합산: +5 누적 +35%, +10 +80%. 수치는 승인한 초기 설정, 플레이 테스트로 조정 가능.

## 6. 공통 재료와 확인할 사항

낡은 털실뭉치 승인 드롭: Ch 1 삐죽 풀벌레·운석 쥐 / Ch 2 끈끈 벌레 / Ch 3 가시 도토리·화난 덩굴 / Ch 5 태엽 쥐·블록 병사 / Ch 8 눈덩이 악동·서리 늑대 / Ch 13 검은목도리 추적자. 무기·보호구·액세서리에 중복 사용 가능. 일반 적 소량 확률·관련 엘리트는 더 많이, 수치 미정.

남은 확인: 각 무기 기본 공격력/주기, 기술별 데미지·냥기력·쿨타임·등급 진화, 단단젤리 외 강화 재료 드롭량, 창 이름. 장갑 5종·검 설계도·전체 무기 전용 3칸은 확정 완료.

이 문서는 기획 정리이며 구현·밸런스 검증 완료를 의미하지 않는다.

## 7. 캣닢 낚싯봉 — 5번째 무기

### 외형·공격
- 고양이 낚싯대 장난감 모양. 손잡이와 끈 끝의 캣닢 장식·리본, 낚싯바늘 없음.
- 기본 공격: 장식 끝에서 작은 캣닢 잎 모양 마법탄을 전방 자동 발사.
- 스킬 속성에 따라 장식의 빛·입자 변화. 기술은 전방 중심 발생.

| 속성 | 전용 스킬 | 효과 |
|---|---|---|
| 불 | 화르륵 불꽃화살 | 여러 불꽃 화살 전방 발사·화상 지속 피해 |
| 물 | 육수 쓰나미 | 큰 전방 파도·광역 피해·적을 호냥이에게서 멀리 밀어냄 |
| 얼음 | 팔랑팔랑 캣닢눈보라 | 전방 구역 위에서 캣닢눈이 내려 동결·이동속도 감소 |
| 번개 | 찌릿 번개웨이브 | 전방 적에 적중 후 주변 적에게 번개 피해 연결 |
| 바람 | 쌩쌩 바람발톱 | 발톱 모양 바람 여러 갈래가 전방으로 벌어지며 관통 |

동결/감속 순서·보스 저항·상성 체계·수치·냥기력·쿨타임·등급 진화는 미정. 속성의 효과 차이부터 구현하고 상성은 이후 검토하는 안.

캣닢 잎·낚싯대 조각·낡은 리본·반짝 가루·향긋한 캣닢 꽃·별빛 리본·무지개 낚싯줄은 이전 후보로, 위 재료가 대체한다.

## 8. 츄르츄르 런처 — 6번째 무기

- 무기명 ‘츄르츄르 런처’, 기본 공격은 작은 젤리 포탄을 전방 자동 발사.

| 전용 스킬 | 효과 |
|---|---|
| 부메랑 털실공 | 전방 관통 후 복귀·감속, 진화 시 실 속박 장판 |
| 향긋 캣닢폭탄 | 전방 캣닢 폭탄으로 수면 부여 |
| 눈물쏙 츄르탄 | 매운맛 츄르탄이 전방 착탄 후 작은 매운맛 구름을 남겨 범위 지속 피해 |
| 꽝꽝참치 대폭탄 | 느리고 큰 포탄 전방 발사, 넓은 범위 강한 순간 폭발 피해 |
| 데굴데굴 열매지뢰탄 | 전방 바닥으로 굴러가 멈춘 뒤 적 접근 시 폭발 |

기존 캣닢 폭탄의 지속 피해는 수면으로 대체. 수면의 피격 해제·보스 판정, 지뢰 유지시간, 피해·쿨타임 등은 미정.
