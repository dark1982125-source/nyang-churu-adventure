## 읽는 법

- 문서에 `미정`·`제안`으로 적힌 것은 확정이 아니다. 구현이 필요하면 `src/config/tuning.ts`에 `TEMP`로 두고 보고서에 선택지로 올린다.
- 과거 문서·ZIP은 현재 규칙으로 자동 갱신된 자료가 아니다.
