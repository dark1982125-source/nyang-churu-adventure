# 냥냥 츄르 대모험

횡스크롤 생존 로그라이크. Phaser 3 + TypeScript + Vite, 브라우저(PC·모바일 가로)에서 실행.

## 실행

```
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 자동 테스트 (화면 없이 전투 로직을 끝까지 돌린다)
npm run build      # 타입 검사 + dist/ 빌드
```

대장간 미리보기: 주소 끝에 `?preview=forge`(또는 `#forge`)를 붙이면 깡깡이 구출·재료 보유 상태의 **임시 저장**으로 시작한다(실제 저장과 분리, 새로고침하면 사라짐). Ch 2가 아직 없어 대장간을 확인할 다른 방법이 없어서 둔 검토용 입구다.

GitHub Pages: 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 main에 합칠 때마다 `.github/workflows/pages.yml`이 배포한다.

조작: PC는 `→`/`D` 전진, `Space`/`↑`/`W` 점프, `1`~`3` 궁극기·선택지. 모바일은 화면 아래 버튼.

## 구조

| 경로 | 내용 |
|---|---|
| `src/config/tuning.ts` | **임시 수치(TEMP) 전부.** 기획 확정값은 `CONFIRMED` 주석 |
| `src/data/` | 적·Ch 1 웨이브·장갑 기술·공통 패시브 14종·궁극기 6분류·동료·재료(무기 6종 전체)·무기 제작/강화표·영구 성장 테스트 노드 |
| `src/sim/battle.ts` | 한 판의 전투 시뮬레이션(Phaser와 분리된 순수 로직) |
| `src/sim/choices.ts` | 호냥이/캠프 3지선다, 등급 진행, 행운 |
| `src/meta/save.ts` | 영구 저장(판 상태와 분리), 영구 성장 구매, 출격 능력치 |
| `src/meta/settlement.ts` | 판 정산(성공/실패 규칙, 중복 정산 방지, 최초 클리어 설계도, 특별 재료) |
| `src/meta/forge.ts` | 대장간: 해금·첫 방문 설계도·제작·강화(실패 보정·천장·특별 재료 보존)·장착 |
| `src/game/` | Phaser 화면: 캠프·전투·결과, 임시 합성 효과음 |
| `tests/` | 이동 제한·처치 카운트·분열·전방 전투·보스 큰 돌·구출·정산·부활·기력·궁극기·선택창·패시브·드롭 수집·대장간 테스트 |

새 무기는 `src/data/skills.ts`의 `WEAPONS`에 같은 형태로 추가한다. 지금 전투에 연결된 무기는 기본 지급 장갑뿐이다.

## 현재 구현 범위

기준 문서 우선순위: `전투흐름-후속확정-20261015.md` → `현재-개발기준.md`·`패시브-확정정리.md` → `무기-6종-기획정리.md` → 누적 기록 마지막 19절.

전투(Ch 1)
- 누르는 동안 오른쪽 전진, 놓으면 정지(확정). 호냥이와 캠프가 함께 움직이고 함께 멈추며 간격 유지. 웨이브 중에는 함께 정차.
- 왼쪽 이동·후퇴·대시 없음. 점프 중에도 적과 호냥이가 서로 넘어가 뒤에 남지 않는다.
- 3웨이브, 끝은 돌돌 운석쥐 / 왕먼지 슬라임 / 쿵쿵 돌발바닥.
- 일반 구간: 목표 처치 수까지 잡몹이 계속 생성(동시 수·간격 제어). 달성 즉시 스폰 중단, 남은 잡몹은 처치 수·보상 없이 제거, 이미 떨어진 드롭은 그대로.
- 엘리트/보스 구간: 본체와 분열·소환체를 전부 처치해야 다음 웨이브. 분열은 세대 상한으로 종료 보장. 일반 목표 카운트와 부하 잔여 수를 따로 셈.
- 보스: 발 구르기 충격파(점프 회피), **캠프를 향해 포물선으로 날아가는 큰 돌**(기본 공격 공중 펀치·전용 기술로 파괴, 놓치면 캠프 피해, 배리어가 흡수).
- 구출: 정체 비공개 감옥 → 보스 열쇠 → 개방 → 정식 구출 → 정산·합류.
- 실패: 주운 재화·재료 보존, 신규 구출 없음, 기존 구출 유지. 판 안 레벨·기술·패시브·다시냥 방울은 매 판 초기화.
- 캠프 멘탈 0은 즉시 패배(방울 무관), 동시 0도 캠프 우선·방울 미발동.
- 판 도중 나가기(Esc/버튼)·앱 종료: 주운 재화·재료만 보존하고 판 종료, 이어하기 없음. 판 저널을 주울 때마다 저장해 다음 실행 때 한 번만 정산.

판 안 성장
- 기본 공격: 별도 슬롯, 무소모, 등급 진화 없음, Lv.1~5.
- 캠프 지원: 합류한 전투 지원 동료 전부 활성(슬롯 제한 없음), 각 판 안 Lv.5.
- 대체 보상: 후보가 부족한 칸만. 호냥이 냥젤리/HP/기력, 캠프 골골기어/캠프 멘탈. 슬롯 없이 즉시 적용(양 TEMP).
- 선택창: 초과 경험치 유지, 호냥이 → 캠프 순, 차례마다 후보 새로 생성, 선택 중 전투 시간 정지.
- 전용 기술: 5종 중 최대 3종, 일반 Lv1~3 → 유니크 Lv1~3 → 전설, 행운으로 상위 등급 직접 제시.
- 공통 패시브 14종: 한 판 최대 5종, 각 Lv.5, 등급 진화 없음. 5종이 차면 새 패시브 제외, Lv.5 패시브 제외, 판 종료 시 초기화.
  - HP 자연 회복은 `체력 회복력 증가` 습득 후에만(피격 대기 없음). 냥기력은 기본 자연 회복 + 패시브로 가속.
  - 최대 HP·최대 냥기력 증가분만큼 현재치도 증가.
  - 공격력(기본·스킬·공격 궁극기) / 스킬 피해(전용 스킬만) / 공격속도(기본 공격 주기만) / 쿨타임(전용 스킬만) / 치명타(호냥이 직접 타격) / 회피(적 직접 공격만, 지속 피해 제외) / 수집 범위(모든 드롭).
- 드롭: 경험치·톱니·재화·재료·방울·캡슐 전부 실제 드롭. 수집 반경 안에서 흡인되어 **호냥이에게 닿아야** 판 획득물·사용. 뒤에 남거나 사라진 드롭은 `놓친 드롭`.

캠프·영구
- 냥기력·궁극기·다시냥 방울·동료 지원(배리어=캠프 보호, 레이저, 코숏 캡슐)은 이전과 같다.
- 대장간(깡깡이 구출 후에만 탭이 보임): 첫 방문에 젤리 펀치 장갑·생선뼈 검 설계도 1회 지급, 나머지는 해당 챕터 일반 최초 클리어. 제작은 재료만 소모(런처만 4종 10/5/5/3).
- 강화(모든 무기 공통표): 100/100/90/80/70/60/50/40/25/10%, 재료 5/5/8/8/15/17/20/23/27/35, 누적 공격력 +5 35%·+10 80%, +5 유니크·+10 전설. 실패 시 기본 재료만 소모·단계 유지·같은 단계 실패당 +5%p·9회 실패 후 확정(실패 기록 저장). 특별 재료는 보유해야 시도, 성공 시에만 소모. 행운 미적용.
- 특별 재료: 지정 챕터 클리어마다 1개(고난도 전설 재료는 본편 Ch 8 이후).
- 장비 슬롯: 무기·몸통 보호구·발 보호구·액세서리 + 코스튬 별도. 장착은 캠프에서만, 장착 무기 강화 보너스가 출격 공격력에 반영.

## 임시로 정한 것 (확정 아님)

- 비교용 개발 도구: 설정의 `[비교] 자동 전진`, `[비교] 점프 통과 + 후방 레이저`. 확정 규칙이 아니다.
- 일반 구간 목표 처치 수·동시 수·간격, 캠프 간격, 대체 보상 양, 패시브 레벨당 수치·상한, 무기 기본 공격력(20), 모든 피해·체력·속도·드롭 수량.
- 캠프 대체 보상은 두 종류라 선택창이 2장일 수 있음(세 칸 정책 미정).
- 판 종료 시 필드에 남은 드롭은 지급하지 않음(자동 회수 미정). 잔여 잡몹 정리 때 기존 드롭·투사체는 그대로 둠(미정).
- 감옥 열쇠는 놓치면 진행이 막히므로 거리와 상관없이 끌려온다.
