# 냥냥 츄르 대모험

횡스크롤 생존 로그라이크. Phaser 3 + TypeScript + Vite, 브라우저(PC·모바일 가로)에서 실행.

## 실행

```
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 자동 테스트 (화면 없이 전투 로직을 끝까지 돌린다)
npm run build      # 타입 검사 + dist/ 빌드
```

대장간 미리보기: 주소 끝에 `?preview=forge`(또는 `#forge`)를 붙이면 깡깡이 구출·재료 보유 상태의 **임시 저장**으로 시작한다(실제 저장과 분리, 새로고침하면 사라짐). Ch 2가 아직 없어 대장간을 확인할 다른 방법이 없어서 둔 검토용 입구다.

GitHub Pages: 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 main에 합칠 때마다 `.github/workflows/pages.yml`이 배포한다.

조작: PC는 `→`/`D` 전진, `Space`/`↑`/`W` 점프, `1`~`3` 궁극기·선택지. 모바일은 화면 아래 버튼.

## 현재 구현 범위

기획 원문은 [`docs/`](docs/README.md)에 보관한다. 우선순위: `보호구-6종-확정정리.md`(보호구)·`캠프보상-전환-클리어-확정.md` → `치료-상태이상-방어-확정.md` → `전투흐름-후속확정-20261015.md` → `현재-개발기준.md`·`패시브-확정정리.md` → `무기-6종-기획정리.md` → 누적 기록 18·19절. 작업 규칙 요약은 [`CLAUDE.md`](CLAUDE.md).

전투(Ch 1)
- 누르는 동안 오른쪽 전진, 놓으면 정지(확정). 호냥이와 캠프가 함께 움직이고 함께 멈추며 간격 유지. 웨이브 중에는 함께 정차.
- 왼쪽 이동·후퇴·대시 없음. 점프 중에도 적과 호냥이가 서로 넘어가 뒤에 남지 않는다.
- 3웨이브, 끝은 돌돌 운석쥐 / 왕먼지 슬라임 / 쿵쿵 돌발바닥.
- 일반 구간: 목표 처치 수까지 잡몹이 계속 생성(동시 수·간격 제어). 달성 즉시 스폰 중단, 남은 잡몹은 처치 수·보상 없이 제거.
- 전환: 적 투사체·장판·예고와 호냥이/캠프의 진행 중 공격 제거, 보호막·버프·쿨타임 유지, 드롭 자동 회수 → 레벨업 선택 → 등장 연출(전투 타이머 정지) → 엘리트/보스.
- 엘리트 처치 뒤에는 레벨업 선택을 마치고 다음 웨이브로. 최종 보스(와 필수 분열·소환체) 처치 순간 클리어 확정: 남은·같은 틱 경험치로 선택창이 뜨지 않고, 남은 드롭은 자동 회수, 경험치 환산 없음. 확정 뒤에는 패배·나가기 없음.
- 엘리트/보스 구간: 본체와 분열·소환체를 전부 처치해야 다음 웨이브. 분열은 세대 상한으로 종료 보장.
- 화면 표시: 일반 구간만 `처치 k/목표`. 엘리트·보스 구간은 `엘리트 전투`/`보스 전투`만 표시하고 분열·소환체 수는 보여 주지 않는다(전멸 판정은 내부 유지).
- 실패·중도 종료는 주운 것만 정산.
- 캠프 위협 시험 적(TEMP, 설정에서 끌 수 있음): A `(시험) 조약돌 투척쥐`는 호냥이 앞에서 조준선 예고 뒤 캠프로 돌을 던지고, B `(시험) 먼지 박쥐`는 공중에서 캠프 위 낙하 그림자 예고 뒤 먼지 뭉치를 떨어뜨린다. 둘 다 펀치·기술·점프 몸 요격으로 막는다. 박쥐는 점프해야 펀치가 닿는다.
- 보스: 발 구르기 충격파(점프 회피), **캠프를 향해 포물선으로 날아가는 큰 돌**(기본 공격 공중 펀치·전용 기술로 파괴, 놓치면 캠프 피해, 배리어가 흡수).
- 구출: 정체 비공개 감옥 → 보스 열쇠 → 개방 → 정식 구출 → 정산·합류. 클리어 확정 순간 저널에 기록하므로, 감옥으로 가는 중 앱이 꺼져도 다음 실행 때 전투 없이 구출 마무리 화면(감옥 개방 → 공개 → 결과)으로 돌아오고, 동료·보상은 그때 한 번만 지급된다.
- 방어력: 영구(테스트 노드) + 장비(보호구, 수치 TEMP) + 판 임시(패시브). 직접 피해(접촉·근접·투사체·폭발) × 100/(100+방어력). 독·화상·출혈·지형 지속 피해는 방어·회피·무적 무관.
- 상태이상(호냥이): 독·화상·출혈·빙결·감속. 같은 DOT는 강한 효과 유지·시간 갱신, 빙결·감속은 시간만 갱신, 종류끼리 공존. 빙결은 이동·점프·공격 정지, 최대 시간 제한, 풀린 뒤 재빙결 면역. 회피하면 그 공격의 상태이상도 무효.
- 적 제어 저항: 수면·기절·빙결은 일반 그대로/엘리트 단축/보스 짧은 감속, 밀쳐내기는 일반 그대로/엘리트 감소/보스 면역, DOT는 전 등급. 보스 기절로 패턴을 끊는 일은 없다.
- 실패: 주운 재화·재료 보존, 신규 구출 없음, 기존 구출 유지. 판 안 레벨·기술·패시브·다시냥 방울은 매 판 초기화.
- 캠프 멘탈 0은 즉시 패배(방울 무관), 동시 0도 캠프 우선·방울 미발동.
- 판 도중 나가기(Esc/버튼)·앱 종료: 주운 재화·재료만 보존하고 판 종료, 이어하기 없음. 판 저널을 주울 때마다 저장해 다음 실행 때 한 번만 정산.

판 안 성장
- 기본 공격: 별도 슬롯, 무소모, 등급 진화 없음, Lv.1~5.
- 캠프 지원: 합류한 전투 지원 동료 전부 활성(슬롯 제한 없음), 각 판 안 Lv.5.
- 대체 보상: 후보가 부족한 칸만. 호냥이 냥젤리/HP/기력. 캠프는 기술 우선, 남는 칸만 골골기어/캠프 체력 회복으로 유효 선택지 수만큼(2개면 2장), 체력 최대면 회복 제외, 기어만 남으면 자동 지급. 양 TEMP.
- 선택창: 초과 경험치 유지, 호냥이 → 캠프 순, 차례마다 후보 새로 생성, 선택 중 전투 시간 정지.
- 전용 기술: 5종 중 최대 3종, 일반 Lv1~3 → 유니크 Lv1~3 → 전설, 행운으로 상위 등급 직접 제시.
- 공통 패시브 14종: 한 판 최대 5종, 각 Lv.5, 등급 진화 없음. 5종이 차면 새 패시브 제외, Lv.5 패시브 제외, 판 종료 시 초기화.
  - HP 자연 회복은 `체력 회복력 증가` 습득 후에만(피격 대기 없음). 냥기력은 기본 자연 회복 + 패시브로 가속.
  - 최대 HP·최대 냥기력 증가분만큼 현재치도 증가.
  - 공격력(기본·스킬·공격 궁극기) / 스킬 피해(전용 스킬만) / 공격속도(기본 공격 주기만) / 쿨타임(전용 스킬만) / 치명타(호냥이 직접 타격) / 회피(적 직접 공격만, 지속 피해 제외) / 수집 범위(모든 드롭).
- 드롭: 경험치·톱니·재화·재료·방울·캡슐 전부 실제 드롭. 수집 반경 안에서 흡인되어 **호냥이에게 닿아야** 판 획득물·사용. 뒤에 남거나 사라진 드롭은 `놓친 드롭`.

캠프·영구
- 냥기력·궁극기·다시냥 방울·동료 지원(배리어=캠프 보호, 레이저)은 이전과 같다.
- 닥터 코숏(Ch 1 구출 후): 캣닢 캡슐(HP)과 증상별 처방 두 갈래. 처방은 빙결 → 감속 → 초당 피해 최대 DOT 순으로 한 번에 약 하나(개다래 정화약=독, 보송보송 붕대=출혈, 시원 민트연고=화상, 캡사이신 핫팩=빙결, 사뿐 냥카스=기술 감속). 같은 약이 이미 떨어져 있으면 다음 증상 약. 도착 즉시 소모, 보관 없음. 예전의 만능 정화약은 없다.
- 코숏의 만능 처방약: 골골기어 테스트 노드(코숏 구출 필요)로 해금. 다섯 증상 동시 해제, HP·지형 둔화 제외.
- 대장간(깡깡이 구출 후에만 탭이 보임): 첫 방문에 젤리 펀치 장갑·생선뼈 검 설계도 1회 지급, 나머지는 해당 챕터 일반 최초 클리어. 제작은 재료만 소모(런처만 4종 10/5/5/3).
- 강화(모든 무기 공통표): 100/100/90/80/70/60/50/40/25/10%, 재료 5/5/8/8/15/17/20/23/27/35, 누적 공격력 +5 35%·+10 80%, +5 유니크·+10 전설. 실패 시 기본 재료만 소모·단계 유지·같은 단계 실패당 +5%p·9회 실패 후 확정(실패 기록 저장). 특별 재료는 보유해야 시도, 성공 시에만 소모. 행운 미적용.
- 특별 재료: 지정 챕터 클리어마다 1개(고난도 전설 재료는 본편 Ch 8 이후).
- 장비 슬롯: 무기 + 보호구 머리·몸통·발 + 액세서리 1칸(나비 미구현이라 비어 있음) + 코스튬 별도. 장착은 캠프에서만, 장착 무기 강화 보너스가 출격 공격력에 반영.
- 보호구(깡깡이, `보호구` 탭): 누빔모자·누빔조끼 설계도는 대장간에서, 탐험헬멧은 일반 Ch 4 최초 클리어, 방탄갑옷·스니커·부츠는 설계도 시점 미정이라 잠김. 제작 수량·재료명은 확정표 그대로이고 재료 창고는 무기와 공유. 강화는 무기 공통 성공률·소모량·실패 보정·10회 보장, 효과는 보호구별(최대 체력·방어력·회피·출혈/기절/화상/빙결/적 스킬 감속 지속시간·밀쳐내기 거리·받는 치명타 피해 감소). 출격 때 한 번만 합산하므로 장착·해제·불러오기·강화로 값이 쌓이지 않는다.
- Ch 1 보호구 재료 드롭(위임 배치, 확률 TEMP): 운석 쥐 → 낡은 천조각·낡은 스웨터, 먼지 슬라임 → 폭신 마시멜로·끈끈 슬라임풀, 왕먼지 슬라임 → 구름 솜사탕. 다른 챕터 획득처는 `src/data/armor.ts` 표로만 준비.

## 임시로 정한 것 (확정 아님)

- 비교용 개발 도구: 설정의 `[비교] 자동 전진`, `[비교] 점프 통과 + 후방 레이저`. 확정 규칙이 아니다.
- 시험 토글: `캠프 위협 A/B 시험 적`(기본 켜짐), `적 상태이상 공격`(기본 꺼짐. 켜면 먼지 슬라임=감속, 풀벌레=출혈, 운석 쥐=화상, 왕먼지 슬라임=독, 보스 충격파=빙결로 치료·처방을 확인할 수 있다. Ch 1 적의 상태이상은 기획 미정).
- 방어 포인트(패시브 10/Lv, 영구 노드 5/Lv), 음수 방어 0 처리, 반올림 없음. 캠프 멘탈에는 방어 공식을 쓰지 않는다(미확정).
