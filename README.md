# 냥냥 츄르 대모험

횡스크롤 생존 로그라이크. Phaser 3 + TypeScript + Vite, 브라우저(PC·모바일 가로)에서 실행.

## 실행

```
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
npm test           # 자동 테스트 (화면 없이 전투 로직을 끝까지 돌린다)
npm run build      # 타입 검사 + dist/ 빌드
```

GitHub Pages: 저장소 Settings → Pages → Source를 **GitHub Actions**로 바꾸면 main에 합칠 때마다 `.github/workflows/pages.yml`이 배포한다.

조작: PC는 `→`/`D` 전진, `Space`/`↑`/`W` 점프, `1`~`3` 궁극기·선택지. 모바일은 화면 아래 버튼.

## 구조

| 경로 | 내용 |
|---|---|
| `src/config/tuning.ts` | **임시 수치(TEMP) 전부.** 기획 확정값은 `CONFIRMED` 주석 |
| `src/data/` | 적·Ch 1 웨이브·장갑 기술·궁극기 6분류·동료·재료·영구 성장 테스트 노드 |
| `src/sim/battle.ts` | 한 판의 전투 시뮬레이션(Phaser와 분리된 순수 로직) |
| `src/sim/choices.ts` | 호냥이/캠프 3지선다, 등급 진행, 행운 |
| `src/meta/save.ts` | 영구 저장(판 상태와 분리), 영구 성장 구매, 출격 능력치 |
| `src/meta/settlement.ts` | 판 정산(성공/실패 규칙, 중복 정산 방지) |
| `src/game/` | Phaser 화면: 캠프·전투·결과, 임시 합성 효과음 |
| `tests/` | 이동 제한·처치 카운트·분열·구출·정산·부활·기력·궁극기·선택창 테스트 |

새 무기는 `src/data/skills.ts`의 `WEAPONS`에 같은 형태로 추가한다. 지금 전투에 연결된 무기는 기본 지급 장갑뿐이다.

## 현재 구현 범위 (Ch 1)

기준 문서 우선순위: `현재-개발기준.md` → `무기-6종-기획정리.md` → `냥냥츄르-최신결정사항.md` 18절.

- 오른쪽 전진·점프만. 왼쪽 이동·후퇴·대시 없음. 호냥이 x좌표는 한 판 내내 줄어들지 않는다(테스트로 확인).
- 3웨이브: 일반 적(먼지 슬라임·삐죽 풀벌레·운석 쥐) → 웨이브 끝 돌돌 운석쥐 / 왕먼지 슬라임 / 쿵쿵 돌발바닥.
- 웨이브 진입 시 캠프 정차, 돌파 후 전진. 적은 전방에서만 스폰, 전방 전투 구역 밖으로 전진 불가.
- 대기·생존 적(분열 자식 포함)이 남아 있으면 엘리트 등장·다음 웨이브·클리어로 넘어가지 않는다.
- 왕먼지 슬라임 분열: 자식을 부모 id·세대로 추적, 세대 상한으로 무한 분열 방지. 화면에는 `남은 적 N (+분열 m)`로 따로 표시.
- 보스 패턴: 발 구르기 충격파(점프로 회피), 돌 던지기(앞에 떨어져 굴러오는 돌, 점프로 회피). 대시 없이 대응 가능.
- 구출: 시작부터 먼 곳에 정체 비공개 감옥 → 보스 처치 시 열쇠 → 감옥 도착·개방 → "닥터 코숏을 구출했습니다!" → 정산·캠프 합류.
- 실패: 재화·재료 보존, 신규 구출 없음, 기존 구출 유지. 판 안 레벨·기술·다시냥 방울은 매 판 초기화.
- 성장: 작은 개다래 → 호냥이 3지선다, 작은 톱니 → 캠프 3지선다. 기본 공격 별도(무소모·최대 레벨), 전용 5종 중 최대 3종, 일반 Lv1~3 → 유니크 Lv1~3 → 전설, 행운으로 상위 등급 직접 제시.
- 냥기력: 자연 회복, 전용 기술은 기력·쿨타임이 모두 준비될 때만 발동하고 발동 시에만 차감.
- 궁극기: 별도 공유 게이지, 기술 실제 발동마다 차등 충전, 시간 자동 충전 없음, 최대 3종 장착. 6종 효과는 검토용 자리표시자.
- 다시냥 방울: HP 0 자동 소모, 최대 HP 50%, 3초 무적, 판당 1회, 캠프 파괴에는 미적용.
- 동료 지원: 수염할아버지 배리어(캠프 보호막)·삐콩이 서치 레이저는 처음부터, 코숏 캣닢 캡슐(호냥이 앞 투하·접촉 사용)은 구출 후 출격부터.
- 영구 성장: 냥젤리/황금 개다래/골골기어로 사는 **[테스트] 노드**만 있다(최종 트리 아님).

## 임시로 정한 것 (확정 아님)

- 전진 방식: 기본은 "전진 입력 중에만 이동". 캠프 화면 설정에서 "자동 전진, 적 앞에서 정지"로 바꿔 볼 수 있다.
- 지상의 적은 호냥이에게 막혀 지나가지 못한다. 호냥이가 점프 중이면 아래로 지나갈 수 있고, 이 경우 `pass`로 기록되며 삐콩이 레이저가 뒤쪽 적을 우선 조준한다.
- 영구 재화·재료는 처치 즉시 판 획득물로 기록(줍기 동작 없음). 경험치·톱니는 자석 범위로 줍고, 뒤에 남으면 "놓친 드롭"으로 기록.
- 감옥 열쇠는 놓치면 진행이 막히므로 거리와 상관없이 호냥이에게 끌려온다.
- 동시 패배: 캠프 파괴를 먼저 판정(방울을 쓰지 않고 패배).
- 배리어 대상(캠프), 레이저 조준 우선순위, 캡슐 주기·위치, 공통 패시브 4종(한도 없음), 모든 피해·체력·속도·드롭 수량.
- 정산 시점: 판이 끝나는 순간 정산·저장. 판 도중 앱을 닫으면 그 판의 획득물은 사라진다.
